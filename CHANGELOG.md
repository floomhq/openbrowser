# Changelog

## 0.1.0 - 2026-05-27

- Added broker-managed browser leases for isolated Chrome sessions.
- Added persistent identity profiles with proxy-aware Chrome launch.
- Added profile replica support for controlled parallel sessions.
- Added local MCP server for same-host agents.
- Added remote MCP server backed by the public OpenBrowser API.
- Added `/openbrowser/v1` bearer-token API.
- Added human auth handoff and active-lease control portals.
- Added rich-text keyboard typing and keypress tools.
- Added sanitized telemetry, feedback issue tracking, and broker audits.
- Added browser-use and OpenBrowser CLI adapters.
