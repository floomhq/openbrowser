# OpenBrowser Brand System

## Positioning

OpenBrowser is the browser infrastructure layer for AI agents.

Core line:

> Real browsers. Real logins. Human in the loop.

The product should feel calm, premium, and infrastructure-grade. Avoid cyberpunk, neon, generic AI dashboards, or anything that reads as a scraping tool.

## Logo

The mark is a nested hexagonal browser identity symbol paired with a bold OpenBrowser wordmark.

Rules:

- Use the full logo in headers, hero sections, docs, and launch graphics.
- Use the mark alone for favicon, app icon, compact nav, loading states, and social avatar.
- Keep clear space around the logo equal to at least the width of the mark.
- Do not add a TM symbol unless legally required.
- Do not stretch, glow, bevel, or recolor with gradients.

Minimum sizes:

- Full logo: 160px wide minimum on web.
- Mark only: 24px minimum in UI, 32px preferred.

## Color

Primary:

- Ink: `#0B1220`
- Surface: `#FFFFFF`
- Slate text: `#475569`
- Hairline border: `rgba(15, 23, 42, 0.08)`

Functional:

- Active / healthy: `#10B981`
- Link / primary action: `#2563EB`

Keep OpenBrowser UI mostly white, translucent white, ink, slate, and one active green. External app logos may keep native colors.

## Typography

- Display: Inter Display, 700-800
- Body: Inter, 400-600
- Code: JetBrains Mono or SF Mono

## Visual style

- light-mode product UI
- Apple-style glassmorphism
- large translucent app shell
- subtle shadows
- thin borders
- real browser session in the center
- profile, proxy, auth, and connection state around it
- washed classical landscape background for hero visuals

## Icon style

Use monochrome line icons for OpenBrowser primitives: lease, profile, human handoff, residential proxy, CDP connection, telemetry, audit.

Use real app logos sparingly only for connected sites and profiles.

## Copy tone

Good:

- "A browser API for agents."
- "Real browsers. Real logins. Human in the loop."
- "Agents lease browser sessions with profiles already signed in."
- "When login is needed, the agent hands control back to a human."

Avoid:

- bypass
- undetectable
- scraping at scale
- generic future-of-work language
